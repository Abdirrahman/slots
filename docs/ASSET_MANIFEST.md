# Slots Racing asset manifest

Milestone 7 ships no third-party assets. Every visual and audio asset below is original in this repository — generated either at runtime from source code or deterministically by the project's own Blender pipeline — and requires no external attribution.

| Asset name | Creator | Source | License / terms | Required attribution | Modifications | Used in |
| --- | --- | --- | --- | --- | --- | --- |
| Workshop Bench Track geometry and environment | Slots Racing project | original in this repository | Project source; not separately licensed | None | Procedural low-poly geometry generated from `workshop-track.json`, including its authored elevation, banking, and per-Lane corner speed limits | Authored Track, barriers, Lane rails, workbench scenery, obstacles, pickups, Hazards |
| Toy slot Car models (`toy-car-starter`, `toy-car-sport`, `toy-car-offroad`, `toy-car-family`) | Slots Racing project | original in this repository | Project source; not separately licensed | None | Generated by `blender/scripts/build_assets.py`: lofted bodies whose wheel arches are grown into the body loft as fender haunches, two-tone canopies carrying a body-coloured roof and beltline, guide blades and braids, dished-rim wheels, low-emission lamps driven from Car state at runtime, contrast-picked roof glyphs, and surface-hugging livery stripes. Exported as untextured GLB with Principled BSDF materials | Racer Cars and state effects |
