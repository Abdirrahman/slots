# Use an authoritative room server

A dedicated server will own speed, lane changes, collisions, pickups, respawns, laps, and finish times instead of a player's browser hosting or clients reconciling outcomes. One authority prevents latency and browser manipulation from deciding boosted impacts or close finishes, while requiring a WebSocket-capable deployment and client interpolation. There is no separate invasive anti-cheat system; authority is part of normal race synchronization.
