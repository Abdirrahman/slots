# Use TypeScript and Three.js on WebGL2

The client will use TypeScript, Vite, Three.js, native HTML/CSS UI, and WebGL2 rather than a general game-engine export. This web-native stack keeps startup and runtime adaptable across integrated graphics while providing enough rendering capability for the modernized low-poly style; Babylon.js, PlayCanvas, Unity, and Godot would add facilities the four-lane simulation does not need. WebGPU remains a later profiling-driven option rather than a launch dependency.
