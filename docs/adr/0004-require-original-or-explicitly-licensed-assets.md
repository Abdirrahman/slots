# Require original or explicitly licensed assets

Slots may use original work and zero-cost third-party assets only when explicit terms permit their use and every condition is followed. It will not copy or extract *Grooverider* assets, distinctive tracks, branding, audio, code, or UI; being a personal learning project does not remove those restrictions. An asset manifest will preserve source, creator, terms, attribution, modifications, and usage so later reviewers can verify the boundary.
