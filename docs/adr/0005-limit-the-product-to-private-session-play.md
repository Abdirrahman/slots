# Limit the product to private session play

The initial product uses guest names and room codes for private friend sessions, with local best times and no accounts, public matchmaking, persistent progression, global leaderboard, analytics, or monetization. This boundary keeps the learning project focused on racing and authoritative multiplayer instead of identity, moderation, privacy, anti-cheat, and live-service operations. These systems should be added only in response to an explicit change in product scope.
