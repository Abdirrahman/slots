# Competitive toy-racing mechanics

Research date: **8 October 2026**. Open [the HTML report](index.html) for the synthesis, comparisons, proposed rule presets, Dining Table Run recommendations and playtest plan.

The report distinguishes publisher/manual facts, directly observed game frames, developer intent, design inference and new-project proposals. It does not claim a reconstructed Grooverider physics or AI model, measured retention, or causal evidence of addiction. “Addictive” is interpreted as enjoyable, voluntary replayability.

Supporting source notes:

- [Grooverider PS2, original Re-Volt PC and modern RVGL](grooverider-revolt.md)
- [Mario Kart 8 Deluxe and Crash Team Racing Nitro-Fueled](kart-racers.md)

Additional primary research is cited directly in the report: Milestone developer interviews; Codemasters chief designer Gavin Cooper's interview; Ubisoft Nadeo's Trackmania documentation and 2026 design guidelines; Ara Shirinian's GDC presentation; and Przybylski, Rigby and Ryan's motivational model paper. Historical feature descriptions do not establish current online service availability.

The HTML contains its own styling, diagram and interaction code. It has no remote fonts, scripts, analytics or image dependencies, works offline, supports small screens and includes a print layout. Supporting Markdown notes and the earlier rewrite plan are optional links. This research task changes no game source or assets.
